# 文献工作台 Demo

这是一个安装在当前 DSH profile 里的客户端插件，用来验证“文献工作台”的核心交互：

- 三栏工作台：左侧分组筛选，中间文章卡片，右侧文章详情
- 分组标签：单选模式下点分组名只选中当前组；勾选复选框进入多选模式后，点分组名或复选框才是加入/移出；多选模式可“取消多选”，并可在“全部文献”上方切换 AND / OR
- 文章多选：复选框、Ctrl/Command 点击、Shift 连选、全选、批量汇总/导出/删除
- 右键菜单：批量加/移分组、打开详情、汇总、导出 RIS、删除
- 可编辑的结构化总结，支持任意大类、文本条目、星级、标签多选、已读标记
- 分组默认模板；一篇论文属于多个分组时自动合并所有分组的大类
- 用户自定义大类，可保存为个人预设或分组默认
- 结论与原文证据的关联
- “待复核”状态与手动更新
- RSS 候选池、AI 初筛标签、已读置灰与“已读/未读”筛选
- 文献网络图、框选多节点、悬停论文卡片、可调聚类、子网络 scope
- 范围证据矩阵
- RIS 导出

安装后的入口：DSH 左侧栏的“文献工作台”图标（一本书 + 网络节点）。

## 真实库模式

默认自动连接本地 `litd`：

- 文献、PDF、总结、RSS 条目、网络图来自 SQLite 和 litd
- 编辑会保存到 litd；订阅的已读状态也保存在 SQLite
- 网络图是真实聚类，不再使用演示节点
- 元数据文献没有 PDF 时不会生成全文总结
- “发给助手”会复制一段分析指令，粘贴到当前会话即可

点右上角“真实库”可以连接本地 `litd` 服务：

- 真实 SQLite 文献列表和分组
- 真实 PDF 导入：拖入文件 / 文件选择器 / 绝对路径
- 导入时把 PDF 复制到 `litd/data/pdfs/`，不依赖原文件位置
- 新导入的 PDF 默认 `未总结`，结构化总结为空白大类；不自动调用模型，也不自动生成规则草稿
- 真实结构化总结；人工总结带 18 条证据 locator，自动草稿也会尝试回填
- 点击证据 chip 显示真实 `bbox_pdf`
- “打开 PDF”调用系统默认阅读器（已在 Windows 上用 Adobe Acrobat 验证）
- “内嵌预览”在 DSH 内打开 PDF iframe；若 Chromium 阻止内嵌 PDF，弹窗内仍可切换默认阅读器
- 可编辑标题/作者/年份/来源/DOI，写回 SQLite 并更新 FTS
- 批量删除论文，同时清理 PDF 副本和索引
- “发现”弹窗支持 arXiv、PubMed、bioRxiv、Europe PMC；默认 Europe PMC，每次 20 条并支持“加载更多”
- 检索结果和文献页都显示期刊/来源；有开放 PDF 时导入全文，否则保存元数据（状态 `未总结`）
- 三栏布局可拖拽调整宽度：拖动分组栏/列表栏右侧边缘；双击分隔条恢复默认 240 / 360
- 检索结果、论文卡片和详情页都显示期刊徽标（按 JCR 分区着色）和 `IF` 标签
- 仅元数据论文（无 PDF）点“AI 总结”会弹出说明，提供来源页和“导入 PDF”入口，不会浪费模型调用
- “追踪”已是真实 RSS / Atom 订阅：左侧订阅源、右侧概述卡片；点击卡片标记已查看并变灰，详情按钮打开悬浮窗
- 订阅条目自动分类为论文 / 新闻 / 评论；详情弹窗里可以手动改判，改判会锁定，刷新不会覆盖
- 只有论文和未分类条目可以“存入库”，新闻和评论只保留阅读状态
- 订阅默认每 6 小时后台刷新，追踪页仍保留“全部刷新”手动入口
- 设置 → 备份 / 恢复：立即备份、查看历史、下载或删除；自动保留最近 12 份
- 恢复支持上传 ZIP 在线执行：先自动备份当前数据，替换后页面自动重载；失败会回滚
- 网络图三栏宽度可拖拽：左侧控制栏、右侧详情栏；双击分隔条恢复默认 230 / 290
- 网络图支持两种真实模式：语义聚类（TF-IDF + 凝聚聚类）和分组聚类（共享论文分组）
- 分组只包含用户创建的分组；共享一个分组即连边，没有分组的论文单独成簇
- 多选论文后，批量栏可直接“分组”，把所选论文加入/移出用户分组
- 多选后“AI 总结”会先确认 token 成本，逐篇生成；无 PDF 或已有 AI 总结的论文自动跳过
- 多选后“校验引用”会逐篇重新定位 quote，更新页码和 bbox，不调用模型
- 主题标签编辑器已隐藏，旧标签数据保留在数据库中但不参与聚类
- 追踪页订阅栏宽度可拖拽，双击恢复 260px；每个订阅源可单独刷新或删除，删除前提示条目数
- 追踪页支持按标题、摘要、来源搜索订阅内容；订阅源可改名、改 URL、单独刷新或删除
- 追踪页新增“AI 检索”：按需求检索 arXiv/Europe PMC，AI 汇总成 RSS 风格卡片，可打开来源或存入库
- 订阅源支持 OPML 导入/导出，可和 Feedly / Inoreader 等工具迁移；导入前会预览并确认
- 多选文献的批量栏支持直接“导出 RIS”和“补全元数据”（DOI/标题 → Crossref 期刊、作者、年份、摘要）
- 订阅条目入库时会识别 DOI，并用 Crossref 补全期刊、作者和摘要
- 追踪页“AI 评分”按新颖性给未评分 RSS 条目打 1–5 星：新机制最高 5 星，资源型最高 2 星，新闻/评论最高 1 星
- AI 评分会调用 DSH 默认模型并消耗 token；只评分未扫描条目，每批最多 20 条；不依赖研究画像，无摘要也可以给高分，只降低置信度
- litd 断开时保留已加载内容；未连接状态下每 20 秒自动重试连接，不再清空文献和分组
- 客户端默认走同源 `/lit/api/*`，由 `@local/lit-model` 代理到 litd；不再写死 `127.0.0.1:8765`
- 追踪工具栏支持“全部已读 / 全部未读”，状态写入 SQLite
- “发现”里可展开筛选：起始年、结束年、期刊包含、最低 IF、IF 年份、JCR 分区（2026）
- 右上角“设置”可编辑结构化总结预设、分组默认结构，以及按年份维护本地 IF 表
- IF 表会按当前库期刊生成“待填”行；影响因子不是公开数据，需要在“设置 → 影响因子表”里按年份填写或覆盖；筛选时按期刊名匹配
- 自动草稿可重新生成
- 没有 `AI 总结` 的论文在总结页显示 **AI 总结** 按钮；调用当前 DSH 默认模型生成，结束后状态标为 **AI 总结**
- AI 总结可点 **标记为已总结** 变为 `已总结`，也可 **撤回已总结** 回到 `AI 总结`
- AI 总结结果尽量回填 quote/page/bbox；失败时保留原总结

`litd` 启动方式见 [service/README.md](../service/README.md)。真实库模式下 RSS 和网络图都走 litd；未连接时顶部横幅会提示。

## 可以试什么

1. 左侧点分组名是单选；勾选复选框进入多选，点“取消多选”或“全部文献”退出多选。多选时可切换 AND / OR。点“管理”改名、换色、新建或删除分组。
2. 中间列表用复选框、Ctrl/Command 或 Shift 多选文章；右键打开统一设置菜单。
3. 点开一篇论文，修改“研究问题”“主要发现”等条目；每个文本大类都可以继续添加条目。
4. 点“模板 / 预设”：添加“阅读状态”、星级评分、标签多选，或新建自定义大类。
5. 修改一条结论的文字，它会变成“待复核”；点 `p.7` 查看模拟原文证据。
6. 点右上角“更新引用”，观察待复核状态被清除。
7. 点“导出 RIS”，得到一个可导入 EndNote 的演示文件。
8. 切到“追踪”，按“AI 推荐 / 未读 / 已读”筛选；已读条目会置灰。
9. 切到“网络图”，拖拽空白处框选多个节点；鼠标悬停节点看论文卡片。
10. 调整 resolution，点“重新聚类”，再点“提取同簇”或“汇总选中”。
11. 真实库点“发现”，搜索 arXiv，选中结果会下载 PDF 并加入库。

## 重置

点右上角“重置”，或清除浏览器 localStorage:

```js
localStorage.removeItem('dsh-lit-demo-v3')
```
